# Ramo Nessa Core

Backend central do ecossistema.

Responsabilidades:
- autenticação/autorização
- matching de motoristas
- localização em tempo real
- máquina de estados
- pricing e comissão
- pagamentos
- notificações
- chat
- auditoria
- integrações externas

A tecnologia final será fechada após a matriz de fontes e a auditoria dos módulos candidatos.
