# Intellectual Property & Brand Policy

This document summarizes the repository's protection rules. The controlling terms
for source-code use are in the root [LICENSE](../LICENSE).

## Ownership

Ramo Nessa is proprietary software. Copyright notices, Git history, commit history,
and repository records are maintained to preserve authorship and provenance.

## Source code

Public access to the repository, if temporarily or permanently enabled, does not
convert the project into open source. No permission is granted to deploy, resell,
white-label, redistribute, or use protected source code as the implementation base
for another product unless the owner provides express written authorization.

## Derivative code

Changing names, colors, filenames, identifiers, structure, syntax, or a limited
number of implementation details does not by itself create permission to reuse
copied protected expression. The project does not grant a license to create
derivatives from protected source code.

This policy does not claim ownership over unprotectable ideas or a genuinely
independent implementation created without copying protected expression.

## Ramo Nessa brand

No repository permission includes permission to use the Ramo Nessa name, logo,
icons, visual identity, trade dress, slogans, screenshots, or confusingly similar
branding for a third-party service.

Do not imply affiliation, sponsorship, endorsement, or official status.

## Secrets and production credentials

No production secret, private key, payment credential, signing key, database
credential, or provider token should ever be committed to the repository.
Public/private repository visibility must never be treated as a secrets-management
control.

## Evidence preservation

Do not rewrite or squash historical authorship solely for cosmetic reasons when it
would destroy useful provenance. Releases and important milestones should retain
traceable commits and tags where practical.

## Permissions

Any exception to these rules must be explicit and in writing from the rights owner.
