# Assets oficiais — Ramo Nessa

## Identidade aprovada

A identidade oficial usa **amarelo/dourado + preto**.

### Passageiro

- ícone: quadrado amarelo com a marca **RAMO NESSA** e estrada;
- splash: fundo amarelo/dourado;
- bundle/application id: `br.com.ramonessa.passenger`.

### Motorista

- ícone: quadrado amarelo com a marca **RAMO NESSA** e faixa **MOTORISTA**;
- futuro bundle/application id: `br.com.ramonessa.driver`.

## Estrutura reservada

```text
apps/passenger/assets/brand/
├── common/
└── passenger/

apps/driver/assets/brand/
```

## Regra

Não substituir a identidade aprovada por ícones genéricos de táxi, carro ou localização.

Os arquivos raster mestres devem permanecer separados dos arquivos derivados de Android/iOS. O Design System é a fonte de verdade para as cores da interface.
