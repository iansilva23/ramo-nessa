TUTORIAL GUIADO

Como configurar sem errar

Produção
  1. 1
    Crie o projeto no Google Cloud

    Use um projeto exclusivo, por exemplo ramo-nessa-prod, e ative o faturamento.

  2. 2
    Ative somente as 4 APIs necessárias
    Maps SDK for Android Maps SDK for iOS Routes API Places API (New)
  3. 3
    Crie 5 chaves separadas

    Duas Android, duas iOS e uma privada para o Core. Não reutilize a mesma chave entre os aplicativos.

  4. 4
    Restrinja cada chave corretamente

    Carregando dados do projeto…

  5. 5
    Coloque cada valor no lugar indicado

    No GitHub abra Settings → Secrets and variables → Actions. Para o Core, o secret de deploy vira a variável GOOGLE_MAPS_SERVER_API_KEY no servidor.

  6. 6
    Volte aqui e valide

    O status do Core ficará verde quando a chave privada estiver disponível. Os APKs também falham no CI se a chave Android correspondente estiver ausente.
