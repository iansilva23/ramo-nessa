# Contributing to Ramo Nessa

Ramo Nessa is a proprietary project and is **not an open-source contribution
project**.

## External pull requests

Do not submit source code, assets, designs, documentation, or other contributions
unless the repository owner has expressly invited or authorized the contribution.

An unsolicited pull request does not grant the submitter rights to Ramo Nessa
materials, and the repository owner is not required to review, merge, retain, or
use it.

## Authorized contributions

Any authorized external contribution must have its ownership and licensing terms
agreed in writing before merge. Contributors must only submit material they have
the legal right to contribute and must not include third-party confidential,
proprietary, or incompatible-licensed material.

## Brand

No contribution process grants permission to use the Ramo Nessa name, logo,
identity, screenshots, or other brand assets outside the official project.

## Security reports

Do not disclose exploitable vulnerabilities in public issues. Use GitHub's private
security reporting mechanism when available, or contact the repository owner
privately through GitHub.
